# 地方競馬Tips コレクター（Chrome拡張機能）

keibanalysis.net の展開予想ページ（`/race/positionmap?raceid=...`）を、日付・競馬場ごとに順番に開いて、各レースのデータを保存します。保存したデータはJSON（日付別）かCSV（1馬1行）で出力できます。

## インストール

1. このフォルダ（`tools/keibanalysis-collector`）をPCに置く（zipなら展開する）。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ。
4. ツールバーのパズルアイコンから「地方競馬Tips コレクター」をピン留めする。

## 使い方

1. 先にChromeで keibanalysis.net を普通に開き、データが表示される状態にしておく（ログインや広告の視聴が必要ならここで済ませる）。
2. 拡張機能のアイコンを押す。
3. 収集期間（開始日〜終了日）、競馬場（未選択なら全場）、取得間隔（初期値8秒）を指定して「開始」を押す。
4. 拡張機能が専用のタブを1つ開き、1ページずつ巡回します。進み具合はポップアップに表示されます。
5. 終わったら「JSON（日付別）」か「CSV（1馬1行）」で出力する（1馬1行CSVには `winPay`=その馬の単勝払戻、`placePay`=複勝払戻、`pay_馬連` などレースの的中組番と払戻「組番:円」も入ります。JSONにはレースごとの `payouts` と、各馬の `winPay`・`placePay` が入ります）。対象は「両方／地方のみ／中央のみ」から選べます（ファイル名に `_nar`・`_jra` が付きます）。

**開催の確認方法**

- 各日について、開催の多い場（門別→大井→園田…）の1Rから順に開きます。
- 1場でもデータが出れば、ページ内のリンクからその日の開催場が分かります。それ以外の場の確認は自動で省きます。
- 開催場ごとに、1Rのリンクから全レースを取得します。
- リンクに載っていないレースに備えて、最終レースの次の番号も1つ確認し、あれば続けて取得します。

**途中で止めた場合**

- 「停止」でいつでも止められます。
- もう一度「開始」を押すと、「取得済みレースは飛ばす」の設定により続きから取れます。

**広告の関門が出た場合**

- 自動で一時停止し、アイコンに「!」が出ます。
- 収集用タブで普段どおり操作して閲覧できる状態にしてから、「再開」を押してください。
- 拡張機能は広告を回避しません。

**人気・オッズ・払戻の補完（結果ページ）**

- 地方の過去レースは、まず keibanalysis の結果ページ `/race/result_race?raceid=...` から人気・確定オッズ・払戻を補完します（`oddsSource`・`payoutSource` = `keibanalysis_result`）。
- 有利な馬・コース適性は、展開予想ページ側（10項目）の値を残します（結果ページは8項目のため）。
- 結果ページで取れなかった場合だけ、以下の netkeiba を使います。

**netkeiba による補完（予備）**

- 「人気・オッズが無いレースは netkeiba の結果ページから補完する」がオン（初期値）の場合の動きです。
- keibanalysis のページに人気・オッズが無いレース（過去分）では、続けて同じタブで netkeiba（地方競馬）の結果ページ `https://nar.netkeiba.com/race/result.html?race_id=...` を開きます。
- そのページから、馬番ごとの人気・単勝オッズを補います。
- 取得済みのレースで人気・オッズが無いものは、「取得済みレースは飛ばす」がオンでも、オッズの補完だけを行います。
- netkeiba の race_id は「年＋netkeiba競馬場コード＋月日＋レース番号」です。競馬場コードは自動で変換します（例: 門別はNAR 36 → netkeiba 30）。
- 補ったオッズは**結果ページの確定オッズ**です（`oddsTiming=final`）。発走前に分かる値ではないので、予想の検証で「購入時点の情報」として使わないでください。
- 補完の結果は `oddsStatus` に入ります。
  - `ok`: 補完できた
  - `name_mismatch`: 馬名が一致しない馬があった（要確認）
  - `not_found`: 結果表が見つからなかった
  - `timeout`: 応答がなかった
  - `no_venue_map`: netkeibaの競馬場コードが分からない
- 1レースにつき開くページが2つになるので、所要時間は約2倍になります。
- netkeiba の利用規約もご自身で確認してください。

**中央競馬（試験対応）**

- 「中央競馬も取得」をオンにすると、土・日・月曜は中央の開催も確認します。
- 中央の過去レースは `/race/result_race?raceid=...` を開きます。中央の過去ページには人気・オッズ・着順・払戻金が入っているので、netkeibaからの補完はしません。
- サイト上の中央の競馬場コードは、74（東京）しか確認できていません。他の場は 70〜79 と仮定して確認しています。
- 当日・今週の中央ページの形式（URL）は未確認です。現在は positionmap を開きます。
- 台風などで平日に代替開催がある期間は、「中央を全曜日で確認」をオンにしてください（1日あたり約10ページ分、時間が増えます）。

**自分で閲覧したページを保存したい場合**

- 「自分で閲覧したページも保存する」をオンにすると、手で開いたページも保存されます。

## 当日分の取得（発走前の保存）

ポップアップの「**当日分を取得**」を押すと、開始日・終了日を今日にして、すぐに巡回を始めます。

- 取得済みのレースも取り直します。
- 発走前なので、オッズの補完はしません。

当日ページにしか無い3項目（AI予想・騎手の対戦成績表・騎手のオッズ帯別3着内率）を、**発走前に保存する**ためのボタンです。

- 朝（各レースの発走前）に1回押すのがおすすめです。
- 後日、同じ日を過去分として取り直しても（人気・オッズの補完など）、発走前に保存した3項目とレーダーチャートの値は消えずに残ります。
- それぞれの取得時刻が `aiPredictionCollectedAt` などに入ります。最初に取得した時刻は `firstCollectedAt` に入ります。

## 保存される項目（1レース）

| 区分 | 項目 |
|---|---|
| レース | raceid、日付、競馬場コード・名、レース番号、レース名、距離、頭数、取得日時（`collectedAt`）、ページ形式（`dynamic`=当日型 / `static`=過去型） |
| 馬ごと | 馬番、枠番、馬名、性、齢、騎手（成績・賞金・斤量）、調教師（成績・賞金・3列目）、**SP**・SP順位、**予想4角位置**（px、`cornerOrder`=前からの順位）、人気、オッズ、**結果**（`finish`=着順の数値、`finishStatus`=確定/取消/除外/中止など） |
| 有利な馬・コース適性 | **斤量・騎手・最終角巧者・スタート巧者・馬との相性**、**馬番勝率・先行力・末脚・あがり・調子**について、項目ごとに上位の馬番（`superiority`）。各馬には「その項目で何番目に挙がったか」（CSVでは `sup_最終角巧者` などの列） |
| 払戻金 | `payouts`: 券種ごとの組番・払戻(円)・人気（結果ページに表示がある場合。中央の過去ページなど） |
| レーダーチャート | 持ち時計・陣営・潜在力・総合力・近走内容（当日型ページのみ） |
| **AI予想**（当日のみ） | `aiPrediction`: 版、信頼度（ゲージ数）、各行の印（◎○▲△★。図形が既知のものと一致しない場合は `不明` とし、図形情報を `markShape` に保存）、展開有利（🚀）・データ特注穴馬（⚡）、馬番・馬名・スコア%。CSVでは各馬の `aiMark`・`aiTag`・`aiScore`・`aiConfidence` |
| **騎手の対戦成績表**（当日のみ） | `riderWinLoss`: 各騎手から見た、他の出走騎手への先着-後着数。CSVでは合計の `riderVsWin`・`riderVsLoss` |
| **騎手のオッズ帯別3着内率**（当日のみ） | `riderOddsRange`: 単勝オッズ帯（〜1.9／2.0〜9.9／10〜19.9／20〜29.9／30〜99.9／100〜）ごとの3着内数・騎乗数・率。CSVでは `riderOdds_帯` に「3着内数/騎乗数」 |

- `raceid` は「日付8桁＋NAR競馬場コード2桁＋レース番号2桁」です。AI NAVIデータとは「日付・競馬場・レース番号・馬番」で結合できます。
- 過去型ページでは、人気・オッズが空欄です（サイト側でそうなっている）。
- 新馬戦など、SPが全頭空欄のレースは `spAvailable=false` になります。

## 注意

- **予想値の時点:** 過去分のSP・予想4角位置・有利な馬が「レース前に表示された値」か「後から計算し直された値」かは未確認です。予想の検証に使う前に、同じレースを発走前と結果確定後に取得して比べてください。保存データの `collectedAt` で取得時刻を区別できます。
- **サイトへの負担:** 取得間隔は8秒以上を推奨します。長期間をまとめて取る場合は、数日〜1週間ずつ分けて実行してください。
- **利用規約:** サイトの規約やrobots.txtで自動取得が禁止されていないか、ご自身で確認してください。
- **ページ構造の変更:** サイトの作りが変わると取得できなくなります。その場合は `extract.js` の読み取り位置を直します。
