# 馬複の結果から逆算した「軸ボーダー・相手・回避レース」探索

基準日: 2026-10-07

## 対象と方法

- **対象:** 地方競馬全レース 2,744R（2026-07-15〜09-28）
- **使う情報:** AI NAVIの複勝能力指数・単勝能力指数（朝の時点で分かるもの）だけ。オッズは使わない。
- **期間の分け方:** 7〜8月で探索し、9月で検証する（6原則どおり）。
- **買い方:** 馬複100円均等の仮想購入。
- **取消・除外の扱い:** 取消は除いて順位を付け直す。除外は返還として扱う。

## 0. 結論

| 問い | 答え |
|---|---|
| 軸にすべき指数のボーダー | **単勝指数が効く。** 複勝1位馬の連対率は、単勝指数40以上で71〜73%、50以上で74〜78%、60以上で約80%。7〜8月と9月でほぼ同じ値になり、安定している。複勝指数だけで絞ると、80以上でも72〜74%。 |
| 相手の指数 | **相手は単勝指数ではなく、複勝順位で選ぶ。** 軸が連対した時の相手は、軸を除く複勝上位3頭で約57%、上位4頭で約72%、上位5頭で約82%を占める。相手は単勝指数20以上が2割しかなく、単勝指数での絞り込みには向かない。 |
| 荒れるので避けるレース | 次のどれかに当てはまるレース（**荒れ注意**）。上位4頭BOXが外れる率が、該当54%前後、非該当36%前後で、3か月とも同じ差が出た。<br>・**12頭以上**<br>・**複勝1位から15以内に3頭以上いる**<br>・**最高単勝指数が30未満** |
| 回収率 | **100%を安定して超える組み合わせはない。** 7〜8月で100%を超えた条件は1,404通り中0。9月だけ100%近い条件もあるが、7〜8月と9月の回収率の相関は0.03で、再現しない。的中率の相関は0.96。 |

**一言でいうと:** 指数で**的中率はコントロールできるが、回収率はコントロールできない**。

## 2. 軸のボーダー（複勝1位馬の連対率、7〜8月 / 9月、件数）

| 複勝指数＼単勝指数 | 条件なし | ≥30 | ≥40 | ≥50 | ≥60 |
|---|---|---|---|---|---|
| ≥50 | .58/.60（2618） | .63/.65（2078） | .71/.73（1174） | .74/.78（478） | .81/.78（136） |
| ≥60 | .62/.65（2035） | .64/.67（1837） | .71/.73（1149） | .74/.78（477） | .81/.78（136） |
| ≥70 | .68/.69（1184） | .69/.69（1145） | .72/.74（913） | .75/.78（436） | .81/.78（134） |
| ≥80 | .72/.74（528） | .72/.75（527） | .72/.76（486） | .75/.78（306） | .80/.77（104） |

- **単勝指数40が最初の大きな段差。** 40以上は70%を超える。単勝指数が30未満の複勝1位馬は、連対率43%以下まで落ちる（逆算表より）。
- 複勝指数は70以上で効くが、単勝指数40以上の条件を付けた後の上積みは小さい（例: 単勝≥40で、複勝≥50は.71/.73、複勝≥80は.72/.76）。
- 2位との複勝指数差も効く。差が3以下だと連対率42%、差が30超だと75%（7〜9月全体）。

## 3. 相手の指数（軸＝複勝1位が連対した時、7〜8月 / 9月）

| 相手の範囲 | 含まれる割合 |
|---|---|
| 軸を除く複勝上位2頭 | 35% / 35% |
| 上位3頭 | 59% / 55% |
| 上位4頭 | 73% / 71% |
| 上位5頭 | 82% / 81% |
| 上位6頭 | 88% / 87% |
| 相手の複勝指数≥50 | 29% / 27% |
| 相手の複勝指数≥40 | 53% / 49% |
| 相手の複勝指数≥30 | 70% / 66% |
| 相手の単勝指数≥20 | 21% / 20% |

- 相手は**複勝順位の2〜5位**が中心で、相手の指数の目安は複勝指数30以上（約7割）。
- 指数の絶対値（例: 複勝指数≥40）で相手を絞ると、レースによって点数がばらつき、取りこぼしが増える。順位で絞るほうが安定する。

## 5. 荒れる（指数どおりにならない）レースの判定

**荒れの定義（評価専用）**

| 種類 | 定義 | 発生率 |
|---|---|---|
| A | 1・2着がAI複勝上位4頭BOXに収まらない | 43% |
| B | 1・2着に複勝1・2位がいない | 21% |
| C | 馬複30倍以上 | 20% |

**2期間で同じ向きに効いた特徴（荒れA率、7〜8月 / 9月）**

| 特徴 | 荒れやすい | 堅い |
|---|---|---|
| 頭数 | 12頭超 .60/.60 | 8頭以下 .30/.33 |
| 複勝1位から15以内の頭数 | 3頭以上 .59/.64 | 1頭以下 .40/.42 |
| 最高単勝指数 | 29.7以下 .56/.55 | 48.3超 .35/.37 |
| 上位2頭の複勝指数シェア | 0.36以下 .57/.65 | 0.49超 .27/.28 |
| 最高AI勝率（fairWin） | 0.30以下 .56/.55 | 0.49超 .35/.35 |

- 競馬場や距離による差は、2期間で揃わなかった（使わない）。
- 9特徴のロジスティック回帰で、9月のAUCは0.62（荒れA）と0.67（荒れB）。単独で最も効く特徴は「上位2頭の複勝指数シェア」で、AUCは0.62〜0.65。**荒れを確実に当てるのは無理で、「荒れやすさ」が分かる程度。**

**単純ルールの効果（7月 / 8月 / 9月）**

| 区分 | 荒れA率 | 荒れB率 | 30倍以上率 |
|---|---|---|---|
| 荒れ注意（12頭以上 or 1位から15以内3頭以上 or 単勝指数30未満） | 54% / 55% / 54% | 29% / 31% / 27% | 29% / 26% / 26% |
| それ以外 | 35% / 36% / 37% | 13% / 17% / 15% | 13% / 17% / 15% |
| 堅いレース（10頭以下・15以内1頭以下・単勝指数40以上） | 31% / 34% / 38% | 11% / 14% / 13% | 11% / 13% / 16% |

**回避の効果（的中率 / 回収率）**

| 買い方 | 区分 | 7〜8月 | 9月 |
|---|---|---|---|
| 軸＝複勝1位（境界なし）→ 複勝上位3頭 | 全レース | 42.3% / 72.7% | 42.6% / 79.1% |
| 同上 | 荒れ注意を除外 | 49.3% / 75.5% | 49.5% / 84.3% |
| 軸＝単勝1位（複勝≥70・単勝≥40・2位との差≥10）→ 単勝上位3頭 | 全レース | 54.4% / 78.4% | 56.2% / 100.4% |
| 同上 | 荒れ注意を除外 | 55.5% / 80.4% | 56.3% / 102.1% |

- 荒れ注意の回避は、**軸の条件が緩い時ほど効く**（的中率が約+7pt）。
- 軸を単勝指数40以上などで絞った場合、荒れるレースの多くがすでに除かれているので、上積みは小さい（+1pt）。
- 回収率の改善は小さく、期間によって変わる。

## 6. 採用／不採用

| 項目 | 判定 | 理由 |
|---|---|---|
| 軸ボーダー「単勝指数≥40（できれば複勝指数≥70）」 | **的中率の目安として採用** | 連対率71〜74%が、2期間でほぼ同じ値になった |
| 相手「軸を除く複勝上位3〜5頭」 | **採用（的中率の調整用）** | 3頭で的中約54%、5頭で約65%（軸条件付き）。指数の絶対値より安定する |
| 荒れ注意の回避（3条件のどれか） | **採用（見送り判定）** | 3か月とも荒れ率の差が約18pt。特に軸条件が緩い時に効く |
| 上記の組み合わせを「利益の出る買い方」として使う | **不採用** | 7〜8月で回収率100%超が0/1,404。9月の100%前後は再現しない |
| 競馬場別・距離別の回避 | 不採用 | 2期間で向きが揃わない |
